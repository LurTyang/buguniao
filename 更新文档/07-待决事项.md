## C · 已知的技术风险

| # | 风险 | 触发里程碑 | 状态 |
|---|---|---|---|
| C1 | **Android WebView 里的 WebDAV** 会遇到 CORS 和证书问题 | M5 | ⏳ 未验证。写任何界面前先用 `CapacitorHttp` 做最小连通验证 |
| C2 | **坚果云免费额度**（上传 1G / 下载 3G 每月）可能不够 | M5 | ⏳ 未验证。实际用一个月看流量 |
| C3 | **FTS5 trigram 索引体积**约为原文 3~4 倍 | M2 | ✅ **已消除**。实测三百章九十万字，索引体积在原文六倍以内，检索毫秒级。且 Electron 内置 Node 自带 node:sqlite，不必引入原生模块 |
| C4 | **CodeMirror 6 的中文输入法兼容** | M1 | ⏳ **待你亲手验证**。跑 `pnpm dev`，用微软拼音、搜狗各写 1000 字，重点看联想候选与光标位置。这一条只能靠人测 |
| C5 | **`@` 语法解析器**最容易出微妙 bug | M3 | ✅ **已消除**。64 个测试覆盖四条规则、转义、代码块、嵌套、边界、语法提示 |
| C6 | **拖拽排序的间隔编号**会耗尽 | M1 | ✅ **已消除**。37 个测试，含「反复拖拽 200 次顺序仍自洽」 |
| C7 | **Prompt caching 静默失效**会让 AI 成本高 10 倍 | M7 | ⏳ 未验证。上线后必须检查 `usage.cache_read_input_tokens` |
| C8 | **unified diff 按行比对，中文长段落让增量比全量还费** | M4 | ✅ **已消除**。加了保险阀：增量不划算时改存快照 |
| C9 | **jsdiff 对损坏补丁悄悄返回原内容**，会给出错误的旧稿而无提示 | M4 | ✅ **已消除**。用记录里的字数做完整性校验 |

> C8 和 C9 是写代码时才发现的，设计阶段完全没预料到 —— 这就是「先打地基再做界面」的价值。

### 开发中产生的规范修正

| 编号 | 修正 | 原因 | 状态 |
|---|---|---|---|
| D-01 | `@` 语法规则 B 追加「@ **恰好一个**」条件 | 否则 `@十七岁@，实为三百余岁` 会被误判为整行浮出。初版曾写作「奇数个」，后由作者定稿为「恰好一个」（R3-01） | ✅ 已定稿，文档与代码一致 |
| D-02 | 伏笔 id 示例从 `f7k2p9` 改为 `f7k2p9x` | 原示例只有 5 位 base36，与「6 位」的规范不符 | ✅ 已改 |
| D-03 | 版本历史增加「保险阀」：增量不比全文小时改存快照 | unified diff 按行比对，中文长段落会让增量比全量还费 | ✅ 已实现 |
| D-04 | 还原版本时用字数做完整性校验 | jsdiff 对损坏补丁悄悄返回原内容，会给作者一份错的旧稿且无提示 | ✅ 已实现 |
| D-05 | 原子写入的临时文件名加进程内单调计数器 | 原本用 `pid + 毫秒`，自动保存/历史/统计三路写入会在同一毫秒撞名，导致丢一次保存 | ✅ 已实现 |
| D-06 | Windows 上 rename 失败时退避重试 | 杀软、搜索索引器、**坚果云客户端**都可能瞬时持有目标文件句柄导致 EPERM。作品文件夹就在坚果云同步目录里，这条几乎必然遇到 | ✅ 已实现 |
| D-07 | `serializeDoc` 改为严格恒等往返 | 原本会在正文前偷偷补一个换行，导致作者第一次保存后编辑器顶上凭空多出一个空行。排版好看交给新建文档时处理 | ✅ 已实现（端到端冒烟抓出来的） |
| D-08 | 索引库改为整库一个 `index.db` | 规范初版写的是每本一个。单库更简单，且顺带支持跨作品检索 | ✅ 已实现，理由见 [02](02-技术架构.md) |
| D-09 | 检索结果返回 `{hits,total,truncated}` 而非数组 | 原本被条数上限截断后界面只能看到 100 条，作者会以为只有这些。数字要诚实 | ✅ 已实现 |
| D-10 | **右键菜单每一项都点不动** | 关菜单用的是 `mousedown` 捕获阶段监听 window，捕获从 window 往下走，于是点菜单项时先把菜单关掉、组件卸载，`click` 根本没机会触发。重命名、删除、换卷、编辑模板全中招 | ✅ 已修（改为判断点击是否落在菜单内） |
| D-11 | 侧边栏触发区从 10px 透明 div 改为 60px 鼠标位置判定 | 10px 太窄，「以为该触发但就是触发不了」；且透明 div 会挡住底下的点击 | ✅ 已实现 |
| D-12 | 左右互换从侧边栏按钮移进设置 | 那是一次性偏好，不该每次打开都重设 | ✅ 已实现 |
| D-13 | 应用菜单全部中文化，并默认收起菜单栏 | Electron 默认菜单是 File/Edit/View 全英文，对中文写作软件很出戏 | ✅ 已实现（按 Alt 显形） |

| D-14 | 归入灵感/覆盖正文时不再无脑加两个换行 | 目标文档是空的时候，`空 +

| D-15 | `writeNewDoc` 增加 `keepBodyAsIs` 选项 | 新建空文档时补一个空行只是排版好看；但从冲突副本、灵感碎片搬过来的正文是有内容的，那一行会直接变成作者正文顶上的空行 | ✅ 已实现 |
