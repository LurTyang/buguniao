# 不咕鸟 0.4.0「不咕之狂潮」测试版

一个反拖延的中文写作软件。**你的稿子是你自己文件夹里的 `.md` 文件**，
用记事本能打开、能读、能改。软件坏了、卸载了、不想用了，稿子都还在。

**buguniao-0.4.0-win-x64.exe** —— 免安装，双击就跑，不写注册表、不留安装记录。
想放 U 盘也行。校验值见同一个 Release 里的 `SHA256SUMS.txt`。

## 第一次打开

1. 选一个放稿子的文件夹。**建议直接选坚果云/OneDrive 的同步目录** ——
   这样换台电脑接着写，不用导来导去。
2. 新建作品时会问一句：**小说 / 剧本 / 游戏剧本**。选错了不要紧，
   回书架右键那本书 →「更改书籍格式」能改。
3. 书架页和三种稿纸各有一份图文教程，第一次进会自动弹。

## 0.4「不咕之狂潮」新加的

这一版专心改**写起来什么感觉**，没堆新功能。

**稿纸**
- **打字机模式**，横竖各一个开关（设置 → 外观）。竖向：当前行永远停在屏幕中间。
  横向：当前列停在水平中央 —— 注意它会**关掉自动折行**，两者是硬冲突。
- **智能替换**：`"` → 中文弯引号、`--` → `——`、`...` → `……`，还能自己加规则。
  只在你敲下那一刻替换，**不动文件里已有的字**；撤销一次退回你原本打的字符。
- **专注模式**：当前段落之外变淡。
- **上下留白、首行缩进**可调（能调成 0）。是显示效果，文件里不存空格。
- 顶栏显示**这一坐写了多少、删了多少、净多少**。点一下清零。
- **便利贴折起来变成小名牌**，不再占一整张卡的宽度。

**外观**
- **书架页也能改外观**了，跟写作页那份是同一个设置。
- 内置主题**砍到三档**（纸白 / 护眼 / 夜间），摆成三个色块，色块就是预览。
  想要别的用「自选样式」——Typora 主题直接能用。
- **能导入自己的字体**（`.ttf` / `.otf` / `.woff2`）。
- **每个主题各自记住字号**。

**导出**
- 多了 **md** 一档：保留语法，换个编辑器能接着写。txt 仍旧是排给人看的。
- 能选**导哪几部分**：正文 / 大纲 / 设定集。
- 新增「中英之间加空格」「收拾多余空格」。
- 修了个漏子：从前 `@` 根本没被处理，导出的 txt 里行首那个 `@` 是带出去的。

**奖状**
- 征文、比赛之类的纪念。**不会自动获得**，由我手动发。
  拿到之后显示在书架你的名字底下。只有你自己看得见。

**修的 bug**
- 拖人物卡到稿纸上会往正文里插一个人名 —— 0.3 就有的问题，不报错不提示。

## 0.3「咕咕之禁城」修了什么

都是你报上来的（完整的一版一版的记录在 [更新日志.md](../更新日志.md)）。

**稿纸**

- **侧边栏钉住之后不会再掉了。** 关掉软件再打开，钉着的还钉着。
- **主题多了三套：护眼（豆沙绿）、纸黄、夜间（近黑）**，加上原来的纸白和墨灰，
  一共五套。设置 → 外观里换。
- **可以自己挑一份 CSS 当稿纸样式 —— Typora 的主题文件直接就能用。**
  设置 → 外观 → 自选样式。它们排版正文用的是 `#write`，稿纸也顶着这个 id，
  所以字体、字号、行距、标题、引用这些会跟着变；侧边栏和按钮不受影响。
- **按 Ctrl+S 之后右上角浮一下**，告诉你距上次手动保存又写了多少字。
  自动保存不弹（那是三秒一次，弹起来能把人逼疯）。
- **右键菜单不会再压住你刚选中的那段字了。** 它会自己挪到旁边去。
- **启动时只弹一个窗**：连胜、今天写了多少、上次写到哪一篇哪一行，
  底下「进入书架」和「回到上次」两个按钮，回车就是回到上次。
  只在刚打开软件、还没进过任何一本书时弹。
- **行首 `@` 跟 `#` 一样顶格了**，而且会上色 —— 它是标记，不是正文。

**游戏剧本**

- **路线图不用等了。** 原来要等自动保存那三秒图才动，现在改一个字它就跟着变。
- **新写法：合并。** 「分歧一下、后面还是同一条线」不用再回到每条分支尾巴上
  补一行了 —— 在合流的那个节点上写一句 `<- 承认、冷场` 就行。
- **新写法：一行写多个去处。** `-> 图书馆、天台、社团` 会自动摊成三个选项，
  选项文字就是节点名。「这个时间段去哪儿」那种写法不用再一条条抄。
- **结局写成 `-> 【结束】`。** 方括号里写什么都算结局名。
  这样你给节点起名叫「结束」也不会把整条线提前掐掉了 ——
  老写法 `-> 结束` 仍然认，只是书里有同名节点时以节点为准。
- **有意绕回前面的节点，写成 `-> ↩节点名`。** 没标记就绕回去的，
  体检会提一句 —— 那多半是两处不小心起了同一个名字。
- **变量那一块重写了。** 现在直接告诉你怎么写（还能一键插进稿纸）、
  每个变量在哪几个节点被改过（点一下跳过去）、哪些变量只在条件里出现过
  却从来没赋过值（用到它的分支永远走不到）。
- **默认的示例文本只在第一篇出现了。** 第二篇起只给一行标题，
  不用再先删二十行李四。剧本也一样。


## 0.2「不咕之境」新加的：对外统计

**别的网站可以读到你的连胜和字数了** —— 就七个数，没有别的。

设置 → 账号 → 对外统计：

1. 先「用浏览器登录」（密码只在浏览器里输，这软件看不见它）
2. 认领一个**对外短名**（小写字母/数字/连字符，比如 `mingting`）
3. 点「现在上传一次」，或者打开「每半小时自动上传」

然后你会拿到一个地址，任何人都能读，不用登录：

```
https://bugu.char46.top/api/v1/u/你的短名/stats
```

贴到你的博客、主页、群公告里，或者让别人的网站直接 `fetch` 它。
返回的就是这七个数：今天写了多少、今天的底线、本周合计、当前连胜、
最长连胜、一起写了多少天，加上日期。

**关于这件事，几句话说清楚：**

- **会发出去的就那七个数。** 页面上一直摆着它们，没登录时也摆着 ——
  你可以先看清楚再决定要不要登录。书名、章节名、正文一个字都不会离开这台电脑。
- **不认领短名就没人读得到你。** 没有短名就没有公开地址。
- **自动上传默认是关着的**，得你自己打开。
- **随时能反悔。** 「删掉服务器上的我」按一下就删干净，连短名一起放回去。
- 想确认别人到底看到什么，点「看看别人读到什么」—— 它走的是公开接口、
  不带你的令牌，跟别的网站看到的一模一样。

不用这个功能完全没关系，不登录整个软件一个功能都不少。


## 这一版能干什么

**写**
- 稿纸、大纲、设定集、便利贴浮出、双链 `[[ ]]`
- 全文检索（中文分词，几十万字也是秒回）
- 版本历史：每次保存都留一份，改错了能翻回去
- 右键菜单：剪切复制粘贴，以及插入各种语法符号

**盯着你写**
- 每日目标：工作日 / 休息日分开设，有底线和理想线两条
- 连胜、补签、请假；每次启动弹一次今天的连胜
- 番茄钟、字数统计、年度热力图
- 里程碑：「多少天写完第一卷」这类

**长篇专用**
- 伏笔：埋在哪、该在哪收、过期没收会标红
- 关联：谁跟谁有关系
- 灵感箱：书架上第一张卡，随手记，回头再归到某本书

**剧本 / 游戏剧本**
- 剧本排版（只改显示，不动文件一个字节）
- 谁的戏多、谁好久没出声、场次重排
- 分支节点图、体检（断头路 / 孤儿 / 死路 / 走不到的分支）
- 从任意节点试玩、导出 Ren'Py / ink 骨架

**AI（要自己填 Key）**
- 兼容 OpenAI 接口的都能用：DeepSeek、Gemini、智谱等
- 续写、润色、抓虫
- **AI 永远不会自己跑** —— 你不点它就不动，也不会偷偷花钱
