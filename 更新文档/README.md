## 一句话定位

**稿子永远是你自己的纯文本文件，软件只是围绕它长出来的一层能力。**

电脑前认真码字，手机上随手记灵感，两端靠坚果云自动同步，
全文检索 / 伏笔追踪 / 版本历史 / AI 资料员 这些能力全部由本地索引提供，
索引坏了随时重建，软件哪天没了，你的稿子一个字不少。

## 已锁定的四条铁律

这四条是整个项目的地基，后续任何功能设计都不得违反：

1. **文件即真相** —— 正文永远是坚果云文件夹里的 `.md` 纯文本，记事本能打开。数据库里的一切都是派生物。
2. **手机只增不改** —— 手机端只能新建灵感碎片和只读查看，不能编辑正文。这从结构上杜绝了同步冲突，而不是靠事后合并。
3. **索引可重建** —— 全文检索、伏笔、关联全部依赖本地索引库；索引库不参与同步，损坏时重扫文件即可复原，不影响任何数据。
4. **AI 永不自动运行** —— 所有 AI 能力必须由作者手动触发，绝不后台偷跑、绝不自动改稿。

## 术语表

| 术语 | 含义 |
|---|---|
| **便利贴** | 设定集文档中用 `@` 语法标记后自动生成的卡片，可拖出来悬浮在稿纸上 |
| **浮出** | `@` 标记的作用：让某段内容显示在便利贴卡片正面 |
| **灵感碎片** | 手机端新建的、尚未归入正文的短文本，一条一个文件 |
| **索引库** | 本地 SQLite 数据库，存放全文检索索引、关联关系等派生数据，不参与同步 |
| **作品** | 一本书 = 一个独立文件夹，含正文、大纲、设定集、元数据 |
