## 1. 一句话

**不登录也能用，一个功能都不少。** 登录只是给你一个对外的身份，
好让别的网站能读到你的连胜和字数。稿子永远在你自己硬盘上 ——
**这软件不往服务器上传一个字的正文**。

## 2. 登录：走系统浏览器（OIDC 授权码 + PKCE）

### 为什么没有密码框

自己做登录框 = 密码要经过我们的进程。那意味着：

- 我们得对「密码有没有被记进日志、有没有被崩溃报告带走」负责
- 换了 IdP、加了两步验证、加了微信登录，全都得跟着改客户端

走系统浏览器（RFC 8252）之后，**软件从头到尾看不见密码**，
只在最后经手一个授权码。界面上因此只有一个按钮。

### PKCE 顶替 client secret

原生应用是**公开客户端**：没有 client secret，也不该有 ——
桌面程序里的任何「密钥」都能被人扒出来。

所以先扔一个只有自己知道的随机串的 SHA-256 过去（`code_challenge`），
换令牌时再把原串亮出来（`code_verifier`）。中间谁截到授权码都没用。
**只用 S256**，不给 `plain` 退路 —— plain 等于没有 PKCE。

### 回调走本机回环

```
http://127.0.0.1:53682/callback
http://127.0.0.1:53683/callback
http://127.0.0.1:53684/callback
```

不用自定义协议（`bugu://`）当主路：**免安装版可能注册不上协议**
（要写注册表），而回环到哪儿都能用。三个端口全登记进白名单，
占用了就换下一个 —— 直接失败的话作者只会看到「登录不了」，
根本不知道是端口被占了。

用 `127.0.0.1` 而不是 `localhost`：后者可能解析到 `::1`、
也可能被 hosts 改掉，而登记进白名单的是写死的那一串。

退出登录用 `/signout` 那一条。

### 必须查、但漏了也照样能跑的四条

这套流程的特点是**错了也能登录成功**，只是安全性没了。所以逐条钉死
（`core/oidc`，44 个测试）：

| 查什么 | 漏了会怎样 |
|---|---|
| 回调的 `state` 对不对 | 别人诱导浏览器打开的回调也会被我们收下 |
| `id_token` 的 `nonce` 对不对 | 旧的令牌可以被重放 |
| `iss` 是不是我们那台 | 换一台 IdP 发的令牌也认 |
| `aud` 里有没有我们 | 发给别的客户端的令牌也认 |

### 关于验签

客户端**不验 id_token 的签名**，这是有意的：令牌是我们自己**直接**
从令牌端点通过 TLS 取回来的，不是从地址栏捡来的 ——
OIDC Core §3.1.3.7 允许这种情况下跳过。它只用来显示昵称。

**真正要验签的是那台读统计的小服务**：它收到的令牌来路不明，
必须拿 Logto 的 JWKS 验，而且要检查 `aud` 是不是自己。

### 令牌存哪

`%APPDATA%/bugu/oidc.enc`，safeStorage 加密。
**绝不进同步文件夹** —— 同步文件夹是会被网盘上传的。
只在主进程里碰，渲染进程拿到的永远是「登录了没有、是谁」。

要 `offline_access`，不然令牌一过期就得重新走一遍浏览器。
过期时刻**提前 60 秒**算，免得卡在边界上发一个必然 401 的请求。

### 配置

| 项 | 默认值 |
|---|---|
| `logtoIssuer` | `https://auth.ferret.icu/oidc` |
| `logtoAppId` | `raiemcmc08eg4mu4le2hc` |
| `logtoResource` | **暂时留空** —— 见下 |

**写死在代码里，界面上不给改。** 给用户一个「登录服务器地址」输入框，
等于给了别人一个可以骗他填的框 —— 填成一台恶意的 IdP，他就把账号
交出去了，而界面上完全看不出异常。换地址是改代码 + 重新打包的事。

### `resource` 和 `stats:write` 暂时不要（2026-08-27 踩过）

第一次真连的时候直接 `invalid_scope: requested scope is not allowed`，
**整个登录进不去**。原因是登录时带了
`resource=https://api.ferret.icu/bugu` 和 `stats:write`，
而那个 API 资源在 Logto 那边还没建。

**为了一个还不存在的功能把登录搞挂，不划算。** 所以现在只要
`openid profile offline_access`；等那台读统计的小服务真的跑起来、
API 资源也建好了，再把 `resource` 填回去。

顺带修了一个更难受的：回调页**不看内容就吐「登录成功」**——
地址栏里明明写着 `error=invalid_scope`，页面上却说成功，
作者只能一脸茫然地回到软件里看红条。现在先判断再决定给哪一页。

IdP 报 `invalid_scope` 时，错误信息里会列出这次要了哪些权限、
该去 Logto 检查哪几个开关 —— 光把 `requested scope is not allowed`
甩出来，作者只会觉得是软件坏了。

**App ID 不是密钥** —— 原生应用是公开客户端，它本来就明文打在客户端里。
真正不能进客户端的是 Machine-to-Machine 那对凭据。

### 还没验的那一段

浏览器那一趟**在无头环境里验不了**：要真开浏览器、要人输密码。
协议那一半有 44 个单元测试钉着，主进程↔渲染进程那一段有冒烟盯着，
**但「点一下真能登进去」得人工试一次**。


## 3. 对外统计服务

**线上：`https://bugu.char46.top`　源码：`server/`　部署记录：`server/deploy/部署.md`**

这台服务的全部工作是：认一下你是谁，把七个整数存下来，再让任何人都能读到。
它**没有存正文的地方** —— 表结构里就那七列，存不下的东西也就漏不出去。

### 地址与版本

```
https://bugu.char46.top/api/v1/...
```

请求和响应都是 JSON。要身份的接口带 `Authorization: Bearer <Logto 访问令牌>`。
**服务地址跟登录服务地址一样写死在代码里**（`core/statsapi` 的 `STATS_BASE`），
界面上不给填 —— 理由同 §2：一个可以被骗着改的地址栏不该存在。

### 服务端认哪种令牌

Logto 发什么样的访问令牌，取决于登录时要没要 API 资源：

| 情况 | 令牌长相 | 怎么认 |
|---|---|---|
| 没要 `resource=`（**现在就是这样**） | 不透明串 | 拿去问 Logto 的 `/oidc/me`，它说是谁就是谁 |
| 要了 `resource=` | JWT | 本地取 JWKS 验签，不用联网 |

两种都实现了（`server/src/auth.ts`），所以将来把 API 资源建起来、
客户端开始带 `resource`，同一份代码自动走更快的那条，两边都不用改。

> **绝不能「解开 JWT 看看 sub 就算了」。** 不验签的 JWT 谁都能伪造 ——
> 把 payload 里的 sub 改成别人的，就能改别人的数据。这一条看不出区别
> （功能完全正常），所以格外容易被当成优化写掉。

### Stats —— 能上传的就这七个

```jsonc
{
  "date": "2026-08-28",   // 本地日期。服务器不猜时区，客户端算好了传
  "todayWords": 1200,
  "weekWords": 5400,      // 本周（周一起算）到今天为止
  "streak": 9,            // 当前连胜天数
  "bestStreak": 21,
  "dailyFloor": 1000,     // 今天的底线目标，0 = 没设
  "daysTogether": 47      // 从第一条码字记录算起一共多少天
}
```

**两边都显式列这七个字段，谁也不偷懒**：客户端 `core/statsapi` 挑一遍，
服务端 `server/src/stats.ts` 再挑一遍。拦的不是同一件事 ——
服务端那道拦「别人乱塞」，客户端那道拦「我们自己不小心多带」。
某天有人往 planReport 里加个 `currentBook`，如果哪一边是 spread，
书名当场就飞出去了，而且两边都不会报错。

### 短名

Logto 给的 `sub` 是一串随机 ID，放进公开地址里既难看又难念，
所以这台服务自己管一张 `sub → handle` 的表。规矩（`server/src/handle.ts`，
客户端 `core/statsapi` 有一份一模一样的）：

- 3–24 个字符，只认小写字母、数字、连字符
- 不能以连字符开头/结尾，不能有连着的两个连字符，不能全是数字
- 保留了 `api`、`admin`、`me`、`stats` 一批系统词

客户端那一份的作用是**在按下按钮之前就把话说清楚**，而不是等一趟
网络往返回来才说；说了算的仍然是服务端。

> **没认领短名 = 没有公开地址 = 没有任何人读得到你。**
> 这是一道天然的闸：认领这个动作本身就是「我确实想公开」。

### 接口

| 方法 | 路径 | 鉴权 | 用途 |
|---|---|---|---|
| GET | `/healthz` | 否 | 活着没有 |
| GET | `/api/v1/u/<handle>/stats` | **否** | ⭐ 别的网站按这个取数 |
| GET | `/api/v1/me` | 是 | 我是谁、上次推的是什么 |
| PUT | `/api/v1/me/handle` | 是 | 认领 / 改短名 |
| PUT | `/api/v1/me/stats` | 是 | 推那七个数 |
| DELETE | `/api/v1/me` | 是 | 把我的数据整个删掉 |

```
GET /api/v1/u/mingting/stats        无需鉴权
200 → { "handle": "mingting", "updatedAt": "2026-08-28T…", …那七个数（平铺）… }
404 → { "error": "没有这个人" }

GET /api/v1/me
200 → { "handle": "mingting", "updatedAt": "…", "stats": {…七个数…} | null }
      // stats 是 null 表示登录了但一次都没推过。
      // 「没推过」和「推过但今天 0 字」在界面上要说成两句不同的话

PUT /api/v1/me/handle    { "handle": "mingting" }   → 200 { "handle": "mingting" }
PUT /api/v1/me/stats     { …七个数… }                → 200 { "ok": true, "handle": "…" }
DELETE /api/v1/me                                    → 200 { "ok": true }
```

几条不能改的：

- **公开接口一律不带令牌。** 带了纯属多暴露一次。
- **公开接口开 `Access-Control-Allow-Origin: *`。** 不开的话别的网站
  就得自己搭个后端来转发，这个接口就白做了。它不认令牌、不带 cookie，
  吐的东西本来就是公开的，开成 `*` 是安全的。
- **查不到就 404，不回 403，也不说「该用户未公开」** —— 那等于告诉
  外面「这个 handle 是存在的」。
- 公开接口缓存一分钟。码字数不是秒级实时的东西。
- 推数是**覆盖式写入**，一个人只留最新的一份。对外要回答的是
  「现在是多少」，不是历史曲线。

### 错误

```jsonc
{ "error": "给人看的一句话" }
```

就是一个字符串，没有 code。客户端读得出来就转述，读不出来
（比如反代吐的 HTML 错误页）就按状态码说一句人话，**不编**。
翻译在 `core/statsapi` 的 `parseStatsError()`，`desktop/main/stats-net.ts` 有测试钉着。

## 4. 客户端这一侧（2026-08-28 打通）

| `desktop/main/stats-net.ts` | 真发请求 + 把错误翻译成人话。不 import electron，9 个测试 |
| `desktop/main/stats-push.ts` | 取令牌、五个动作、自动上传的钟 |
| `renderer/components/StatsShare.tsx` | 设置 → 账号 → 对外统计 |

### 三道闸

「有东西离开这台电脑」这件事要**三样齐了**才发生：

1. **登录了。** 拿不到令牌就当场说「重新登录一下」，不发一个注定 401 的请求。
2. **认领了短名。** 没短名就没有公开地址，谁也读不到。
3. **自己按了。** 手动「现在上传一次」，或者自己打开自动上传的开关。

`statsAutoPush` **默认 false**，冒烟里有一条专门钉这个。
「装完软件就默认在往外发」这种事只要发生一次，作者就再也不信这个软件了。

### 自动上传

开着的话隔**半小时**推一次，开机后先等 20 秒再推第一次。
每次醒来都重新问一遍「开关开着吗、登录了吗」，所以钟挂早了也不会乱发。

**不做成秒级实时**：对外要回答的是「他最近在写吗」，不是「他这一分钟
写了几个字」—— 后者既没人需要，又意味着作者一边写一边有东西在往外发，
那是另一种感觉。

自动上传失败**绝不打断写作**：记一句话，作者哪天翻到账号页会看见，不弹窗。

### 界面上必须有的三样

1. **会发出去什么** —— 那七个数就摆在按钮上面，**没登录时也摆着**。
   「先看清楚再决定」不该需要先登录。
2. **别人看到什么** —— 「看看别人读到什么」走的是公开接口、不带令牌，
   跟别的网站同一条路，原样吐 JSON。自己看自己的特权视图会骗人。
3. **怎么反悔** —— 「删掉服务器上的我」跟别的按钮一样显眼。
   做不到彻底删除的公开功能不该上线。

### 还没验的那一段

**「真登录一次然后真推上去」得人工试。** 无头环境里登不了浏览器。
钉住的部分：协议 44 + 22 个单元测试、发请求那层 9 个、
冒烟 250 步（含「没登录时按上传会被当场挡下来」）。
线上那台也单独验过：healthz 200、查无此人 404、无令牌推数 401。

**中间那一环 —— Logto 发的不透明令牌能不能过服务端那关 —— 只能真登一次才知道。**
